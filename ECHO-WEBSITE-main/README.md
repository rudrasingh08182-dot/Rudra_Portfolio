# Rudra Pratap Singh — Portfolio

A personalized portfolio adapted from the ECHO editorial portfolio template. The original scroll-expansion media, 3D WorksWheel, OGL liquid FlexCarousel and horizontal experience canvas have been retained and populated with Rudra’s projects.

## Run locally

Requirements: Python 3.

```bash
python -m http.server 8080
```

Open http://localhost:8080.
